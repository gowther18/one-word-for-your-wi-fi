One word, 8 characters: **Goldfish** — the Wi-Fi forgets everything in three seconds, just like a goldfish. It drops your device, forgets the network it joined yesterday, and asks for the password again like it has never met you. The field of 414 is saturated with Ghosting (53 copies) and Gaslighting (32); Goldfish takes the memory angle nobody else used, and as a network name it is one the sponsor would actually want to wear. This program writes that one word to /output/entry.txt.

## Run it

```sh
python3 main.py
```
